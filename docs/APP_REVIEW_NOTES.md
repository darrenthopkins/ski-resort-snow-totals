Lift – App Review Notes

Overview
Lift is a ski day planning app that aggregates recent snowfall and forecast data to help users identify the best nearby ski day.

No Login Required
The app does not require account creation or login.

Location Usage
Lift requests location access to:
- Calculate distance to ski resorts
- Sort results by proximity

If permission is denied, the app uses a default regional location.

Data Sources
Lift consumes public weather and snowfall data from third-party providers.
No user data is collected or transmitted.

How to Test
1. Launch the app.
2. Allow location permission (optional).
3. Tap different days in the horizontal day selector.
4. Observe score updates and resort sorting.

There are no hidden features or gated content.
